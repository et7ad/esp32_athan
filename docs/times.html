Add your mosque

Open an issue on GitHub with your mosque's yearly timetable: a link to it, or the file itself (a PDF, a spreadsheet, a photo of the printed one). Once it is added, it appears on every clock's list by itself, with no firmware update.

Please include the mosque's name as it should show on the clock, where it is (a map link is perfect), and whether the timetable has iqama times.

For whoever adds it

A mosque is one entry in docs/athantimes/mosques.json, one file per year made by the scripts (they read a PDF, a web page or a table and check every day), and a row in the owners' guide. The checks in firmware/tests/run_tests.sh make sure the three agree.
